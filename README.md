## 🛠️ Bahasa yang Digunakan
Bahasa yang digunakan disesuaikan dengan program pada setiap bab, seperti:

**HTML**, **CSS**, **JavaScript**, **PHP** atau bahasa web lainnya jika diperlukan.

## 🚀 Cara Menjalankan Program
1. Pilih folder bab yang ingin dipelajari.

2. Jalankan program sesuai dengan bahasa yang digunakan.

3. Untuk file HTML sederhana, buka file index.html melalui browser.

4. Untuk program PHP, gunakan server lokal yang sesuai.

## 🎯 Tujuan
1. Memahami dasar-dasar pemrograman web.

2. Mempelajari pembuatan halaman web sederhana.

3. Mempraktikkan materi melalui contoh program.

4. Menyimpan dan mendokumentasikan hasil pembelajaran menggunakan GitHub.
